## 🔢 Numbers & Math (ម៉ូឌុលលេខ និងគណិតវិទ្យា)

ប្រើតាមច្រកតែមួយ `src/index.mjs` (ES module, Node.js, គ្មាន `eval`)។

- `Rational`: ប្រភាគពិតប្រាកដដោយ `BigInt` (`0.1 + 0.2 = 3/10`)
- `numberToWords(n, "en" | "km" | "zh")`: អានលេខជា ៣ ភាសា (តិចជាង 10^18)
- `convert(value, from, to)`: បម្លែងឯកតាប្រវែង ម៉ាស ពេលវេលា សីតុណ្ហភាព ល្បឿន កម្លាំង សម្ពាធ ថាមពល
- `classifyAngle`, `degToRadPi`, `radiansApprox`: មុំ (រ៉ាដ្យង់ជាមេគុណ π ពិតប្រាកដ)
- `rectangleArea`, `triangleAreaSquared`, `circleAreaPi`: រូបធរណីមាត្រ
- `solveLinear`, `solveQuadratic`, `exactSqrt`: សមីការលីនេអ៊ែរ និងសមីការការ៉េ (ឫសសនិទានពិតប្រាកដ ឬទម្រង់ `p ± √D`)
- `solveSystem2`: ប្រព័ន្ធសមីការលីនេអ៊ែរ ២ អញ្ញាត (ចម្លើយតែមួយ គ្មានចម្លើយ ឬច្រើនឥតកំណត់)
- `sum`, `mean`, `median`, `mode`, `range`: ស្ថិតិមូលដ្ឋាន (ពិតប្រាកដដោយ `Rational`)
- `polyAdd`, `polyMul`, `polyEval`, `polyDivide`, `rationalRoots`: ពហុធា (មេគុណពីដឺក្រេខ្ពស់ទៅទាប) ចែកពហុធា និងរកឫសសនិទានពិតប្រាកដ
- `matMul`, `matDet`, `matRank`, `matInverse`, `solveSystem`: ម៉ាទ្រីស determinant និងប្រព័ន្ធសមីការ n អញ្ញាត (ពិតប្រាកដ អតិបរមា 50×50)
- `powInt`, `logExact`: ស្វ័យគុណចំនួនគត់ពិតប្រាកដ និងលោការីតពិតប្រាកដ (ឧ. `log₂8 = 3`; បើមិនសនិទាន ត្រឡប់ `null`)
- `trigExact`, `exactToString`, `sinApprox`, `cosApprox`, `tanApprox`: ត្រីកោណមាត្រ (ពិតប្រាកដសម្រាប់មុំ 30°/45° ឧ. `√3/2` ហើយប្រហាក់ប្រហែលត្រឹម 30 ខ្ទង់)
- HTTP API (`npm start`, លំនាំដើម `127.0.0.1:3100`): `POST /v1/call` ជាមួយ `{"fn":"convert","args":["1","km","m"]}`, `GET /v1/functions`, `GET /health` (body អតិបរមា 64KB, `Rational` ត្រឡប់ជាអក្សរប្រភាគ)
- `getConstant(id)`, `listConstants()`: ថេរគណិតវិទ្យា/រូបវិទ្យា (`c`, `h`, `e_charge`, `k_B`, `N_A`, `g_n`, `atm`, `G`, `pi`, `e`) មានប្រភព កំណែ ឈ្មោះ ៣ ភាសា និង `kind` (`exact` ឬ `approximate`)
- `cAdd`, `cSub`, `cMul`, `cDiv`, `cConj`, `cAbs2`, `cPowInt`, `cToString`: ចំនួនកុំផ្លិចពិតប្រាកដ (`[re, im]` ឧ. `["1","2"]` = 1+2i)
- `add`, `sub`, `mul`, `div`: បូក ដក គុណ ចែក ពិតប្រាកដ (ទទួលអក្សរលេខ ឧ. `"0.1"`, `"3/4"`; ចែកនឹង 0 ឲ្យ `DIVISION_BY_ZERO`)
- `speed`, `force`, `weight`, `kineticEnergy`: មេកានិច SI (ល្បឿន v=d/t, កម្លាំង F=m·a, ទម្ងន់ W=m·g_n, ថាមពលស៊ីនេទិច E=½mv²) ពិតប្រាកដដោយ `Rational`
- `density`, `pressure`, `work`, `power`: ដង់ស៊ីតេ ρ=m/V, សម្ពាធ P=F/A, កិច្ចការ W=F·d, ថាមពល P=W/t (SI ពិតប្រាកដដោយ `Rational`)
- `molesFromParticles`, `particlesFromMoles`, `molesFromMass`, `massFromMoles`: គីមីវិទ្យាមូលដ្ឋាន ម៉ូល n=N/N_A, N=n·N_A, n=m/M, m=n·M (ប្រើ `N_A` ពិតប្រាកដ; ម៉ាសម៉ូលេគុល M ជា g/mol ដែលអ្នកផ្តល់)

## 💻 ភាសាកូដ (Languages)

មុខងារគណិតវិទ្យា (បូក ដក គុណ ចែក ពិតប្រាកដ) មានក្នុងគ្រប់ភាសាខាងក្រោម។ រូបវិទ្យា និងគីមីមូលដ្ឋានក៏មានដែរ លើកលែងចំណុចដែលបានកត់សម្គាល់។

| ភាសា | ថត | មាន |
|---|---|---|
| JavaScript (MJS) | `src/` | ទាំងអស់ (ពេញលេញបំផុត៖ លេខធំគ្មានដែនកំណត់, HTTP API) |
| TypeScript + TSX | `tsx/` | គណិត + Calculator (React) |
| JSX | `jsx/` | Calculator (React) ប្រើ `src/index.mjs` |
| JavaScript (កម្មវិធីរុករក) + HTML + CSS | `web/` | ទំព័រ `web/index.html` បើកដោយផ្ទាល់ (ទាំងអស់) |
| Python | `py/` | ទាំងអស់ |
| C | `c/` | គណិត មេកានិច ម៉ាស↔ម៉ូល |
| C++ | `cpp/` | គណិត (`rational.hpp`) + មេកានិច និងម៉ាស↔ម៉ូល (`science.hpp`) |

ចំណាំ៖ C និង C++ ប្រើចំនួនគត់ ៦៤-bit ដូច្នេះលទ្ធផលលើសដែនកំណត់បោះ `OVERFLOW` (មិនឲ្យចម្លើយខុសស្ងាត់ៗ) ហើយមុខងារម៉ូល↔ភាគល្អិត (ដែលប្រើ `N_A` ≈ 6×10²³) មិនមានក្នុង C/C++ ទេ។ HTML និង CSS មិនគណនាខ្លួនឯងទេ ទំព័រ `web/` ប្រើ `web/eit.js` គណនា។
